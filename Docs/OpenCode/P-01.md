### Scope


### Facts (verified at the pinned commit)
- `SearchPatientsGlobalQuery.cs:7-10` — four members: `Text`, `Page`, `PageSize`.
- `SearchPatientsGlobalQueryHandler.cs:28-29` — base query is `.Where(p => !p.IsDeleted)`.
- Handler lines 31–45 — the **single** guard clause `if (!string.IsNullOrWhiteSpace(term))` wraps every current predicate.
- Handler lines 47–50 — ordering then `Skip`/`Take`.
- `Patient.TreatingDoctorId:29`, `ReferralEntityId:31`, `Sex:19`, `AgeValue:21`, `AgeUnit:23`, `RegistrationDateUtc:37`.

### Implementation
1. **Append six optional parameters with defaults** to the positional record — `ExternalEntityId? TreatingDoctorId`, `ExternalEntityId? ReferralEntityId`, `int? TestId`, `Sex? Sex`, `AgeValueBand? Age`, `DateOnly? From`, `DateOnly? To`.
   - **Record discipline:** appended at the tail, all defaulted. **Never insert a member in the middle** — the positional shape is part of the public surface.
   - The six *filters* include F5, which is one function producing a `From`/`To` pair.
2. **Six independent, AND-combined guard clauses** — one per filter, each shaped like the existing term guard. They are **not** nested inside the `Text` clause, because a filter is meaningful with an empty text box. Each is inert when its parameter is null.
3. **Predicate bodies (each must narrow):**
   - doctor → `p.TreatingDoctorId == value`
   - referral entity → `p.ReferralEntityId == value` — a **separate** clause over a **separate** column (SD-6)
   - test → `.Where(p => _db.Set<PatientTest>().Any(pt => pt.PatientId == p.Id && pt.TestId == value))` — verify the exact `PatientTest` key idiom in the codebase before writing it
   - gender → `p.Sex == value`
   - age → an `AgeUnit`-aware band comparison that **compares like with like** and performs no unit conversion
   - date range → `p.RegistrationDateUtc` between the two bounds
4. **Do not touch** the `Text` clause, the phone pre-query, `!p.IsDeleted`, the ordering, or the `Skip`/`Take` chain (C-8, SD-5).
5. **Validator**, if the feature already has one — verify first, do not assume; do not create a second validator shape for a query that has none.

### Guardrails — every clause is mandatory here
- Every new predicate lives in its own `if (parameter is not null)` clause. No predicate is applied outside a guard.
- **No new parameter may replace, widen, or remove the existing `Text` guard.**
- Paging chain untouched: no edit to `Page`, `PageSize`, the ordering, `Skip` or `Take`.
- `PageSize` default stays 50. No 100 literal is introduced (SD-7, C-1).
- Every predicate is a narrowing `&&`, never a broadening `||` on a patient column.
