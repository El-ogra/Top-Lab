## B. Target behaviour and business rules

### B.1 R-F05 — Banded result monitor

**Behaviour.** The operator chooses one test, a minimum value, a maximum value, and a period; the screen lists every result of that test, in that period, whose numeric value falls inside `[Min, Max]`, with the patient context the reference specifies: **date, patient, patient data, referral entity, test, result, status**. A print action writes the same grid to a PDF at a user-chosen path.

| # | Rule |
|---|---|
| BR-F05-1 | `TestId` is **required** and must exist in `Test`; otherwise `Error.NotFound("التحليل غير موجود.")`. |
| BR-F05-2 | `From`/`To` are `DateOnly?`, defaulting to today from `IDateTimeProvider` (mirrors `GetPatientCountStatisticsQueryHandler.cs:29-31`). The period is half-open on UTC day boundaries: `>= From 00:00:00` and `< To+1 00:00:00` — the exact pattern at `:32-33`. |
| BR-F05-3 | The date column filters on **`PatientTest.EnteredAtUtc`** (the result-entry instant), not `CreatedAtUtc` (order time) and not `RegistrationDateUtc`. Rows with `EnteredAtUtc == null` are excluded by construction. |
| BR-F05-4 | Band comparison is **inclusive on both ends**: `Min <= value <= Max`. |
| BR-F05-5 | A value is included only if `ResultFlagComputer.TryParse(value, out v)` succeeds — i.e. `decimal.TryParse(value.Trim(), NumberStyles.Any, CultureInfo.InvariantCulture, …)`. Non-numeric results (`"Negative"`, `null`, whitespace) are **excluded** and are **not** an error. Reuses the existing rule verbatim. |
| BR-F05-6 | `Min > Max` is `Error.Validation` from the validator, message `الحد الأدنى يجب ألا يتجاوز الحد الأقصى.` |
| BR-F05-7 | `From > To` is `Error.Validation`, message `بداية الفترة يجب ألا تتجاوز نهايتها.` — verbatim the existing wording at `GetPatientCountStatisticsQueryValidator.cs:11`. |
| BR-F05-8 | The query is gated on `StatisticsAccessPolicy.Statistics` (`"STATISTICS"`), exactly like the other four. |
| BR-F05-9 | Patient rows that are **soft-deleted** (`Patient.IsDeleted`) are excluded — the same guard as `GetPatientCountStatisticsQueryHandler.cs:36` and `GetTestCountStatisticsQueryHandler.cs:45`. |
| BR-F05-10 | "Status" is the row's own lifecycle, rendered from existing columns only: `IsDelivered` → `تم التسليم`; else `IsPrinted` → `تمت الطباعة`; else `IsReviewed` → `معتمد`; else `غير معتمد`. No new persisted state. |
| BR-F05-11 | Ordering: `EnteredAtUtc` ascending, then `PatientTestId` ascending (deterministic). |
| BR-F05-12 | The referral entity resolves through `ExternalEntity.Name`; a null `ReferralEntityId` renders `بدون جهة إحالة`, reusing the constant at `GetPatientCountStatisticsQueryHandler.cs:14`. |
| BR-F05-13 | The PDF writer is a **separate port over a separate DTO** (the `ICustomGroupPdfWriter` / `IPriceListPdfWriter` precedent). ### L.4 Measurement that decided defect 6

A standalone probe was compiled and executed to settle whether `NumberStyles.Any` with `InvariantCulture` accepts a comma decimal separator. **Result — the draft's claim is false, and `NumberStyles.Number` is no better:**

| Input | `NumberStyles.Any` + Invariant | `NumberStyles.Number` + Invariant | Dot-only check (BR-F05-17) |
|---|---|---|---|
| `3.5` | `3.5` | `3.5` | `3.5` |
| **`3,5`** | **`35`** | **`35`** | **rejected** |
| `0,5` | **`5`** | **`5`** | rejected |
| `12,5` | **`125`** | **`125`** | rejected |
| `1,234.5` | `1234.5` | `1234.5` | rejected |
| `1.234,5` | fails | fails | rejected |
| `Negative` | fails | fails | rejected |
| `""` / whitespace | fails | fails | rejected |
