## 2. Settled Business Rules (fixed — not open decisions)

These rules are settled facts encoded directly in the slices below. They are not alternatives and must not be reopened:

1. **Per-sample lab binding (OD-16-A).** The external lab is chosen when each sample is dispatched (`SentOutSample.ExternalLabEntityId`); the entity must exist and be of type `EntityType.PartnerLab`. No default-lab column on `Test`.
2. **Eligibility.** A sample can be dispatched only for a test with `Test.IsSentOut == true`; the patient must exist and not be soft-deleted; the `PatientTest` must exist.
3. **One dispatch per patient-test.** Re-sending the same `PatientTestId` is rejected (logical uniqueness): `Error.Conflict("تم إرسال هذه العينة مسبقًا.")`.
4. **No cancel/re-send (OD-16-B).** No void/status mutator ships; nothing in this module deletes or cancels a recorded sample.
5. **Pricing (OD-16-D).** `SendSampleOut` defaults `costPrice`/`patientPrice` from `Test.SentOutCostPrice`/`Test.PatientPrice` and accepts explicit overrides; Domain guards require both ≥ 0.
6. **Payments.** `SentOutSamplePayment` requires `amountPaid > 0`; partial payments («ترسل إلى») may not exceed the remaining amount (`Error.Conflict("مبلغ الدفع يتجاوز المتبقي.")`); «خلاص» records a single payment equal to the computed remaining via `SentOutAccountCalculator`; every payment records `PerformedByUserId = ICurrentUserService.UserId` and `PaidAtUtc = IDateTimeProvider.UtcNow`.
7. **Settlement formula single-sourced.** `Remaining = TotalCost − TotalPaid`; `IsFullySettled = TotalPaid >= TotalCost` (Data Model §8.3) — Domain calculator only, never restated in Application.
8. **Permission gate (OD-16-C).** All three write commands carry `IAuthorizedRequest` with `RequiredPermissionCode => "CASH_DISBURSE_DEPOSIT"` (seeded id=11; reuse via `PatientBillingAccessPolicy.CashDisburseDeposit`). Read queries are open.
9. **Follow-up reads (FR-M16-002/004).** The period query filters on `SentAtUtc` (inclusive UTC calendar days), optionally by `ExternalLabEntityId`; the lab-account query returns the dispatch count for the period + account totals (`TotalCost`/`TotalPaid`/`Remaining`) via the Domain calculator.
