## 1. Executive Summary

Module 10 delivers the restricted **P/T audit & traceability** read surface: a patient-level **P view** (registering user, modification count, last modifying user, payment-receiving users with timestamps) and a per-test **T view** (entered / reviewed / printed+count / delivered, each with user and UTC time). Both views are pure queries over columns that already exist at HEAD — **the physical schema is complete**; no migration is needed and the S3 zero-drift gate proves it. Access is gated on the seeded `PT_AUDIT_ACCESS` (id=13) permission with the pipeline's absolute-permission bypass (FR-M17-008).

**Slicing:** 3 slices: S1 Application P-view read → S2 Application T-view read → S3 tests + zero-drift proof + close-out. Presentation slices do not exist in this plan because all UI work is out of scope.

## 2. Settled Business Rules (fixed — not open decisions)

1. **Zero storage change (SD-10-1).** No entity, column, table, index, configuration, or migration is created or modified.
2. **Restriction (SD-10-2/SD-10-3).** Both queries implement `IAuthorizedRequest` with `RequiredPermissionCode => "PT_AUDIT_ACCESS"`; denial returns the shared pipeline Forbidden message verbatim; `IsAbsolutePermission` bypasses.
3. **P view (SD-10-5).** `GetPatientAuditQuery(PatientId)` → registering user + UTC time, `ModificationCount`, last modifying user + UTC time, and the distinct ordered list of payment-receiving users (`ReceivedByUserId`, resolved name, `OperationAtUtc`) across **all** payment operations of the patient, voided included.
4. **T view (SD-10-6).** `GetPatientTestAuditQuery(PatientTestId)` → one row with entered/reviewed/printed/delivered user ids, resolved names, UTC timestamps, and `PrintCount`.
5. **Name resolution (SD-10-4).** Dictionary over `Users`; unknown/deleted user id renders as the raw id string.
6. **Soft-deleted patients remain auditable (SD-10-7).** No `IsDeleted` filter; unknown id → `Error.NotFound("المريض غير موجود.")` / `Error.NotFound("التحليل غير موجود")`.
7. **Read-only (SD-10-8).** No handler mutates any entity; no Domain change anywhere in the diff.
