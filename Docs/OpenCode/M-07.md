## 2. Settled Business Rules (fixed — not open decisions)

These rules are settled facts encoded directly in the slices below. They are not alternatives and must not be reopened:

1. **Print eligibility.** No line enters a combined report unless `PatientTest.IsReviewed == true` (Blueprint line 241); violation → Domain rejection translated to `Error.Conflict("لا يمكن إدراج نتيجة غير معتمدة في التقرير.")`.
2. **Ephemeral combined selection (OD-07-B).** The user's ordered pick of `PatientTest` lines lives in a Domain ValueObject/aggregate-style object validated in memory; nothing is persisted. No `CombinedReport` table, no migration.
3. **PDF-first printing (OD-07-A).** `IReportPrintingService` is implemented in Infrastructure as PDF generation (same writer family as `PatientReportPdfExporter`) followed by dispatch to the assigned printer; all report settings are read **at print time, never cached** (Blueprint §6).
4. **History identity (OD-07-C).** `HistorySortMode.ByLabCode` → rollup by shared `Patient.LabId` (exactly the M-08 `GetVisitHistoryQueryHandler` pattern); `ByPatientName` → rollup by **exact normalized full name** (trim + case-fold) only. No fuzzy matching under any outcome.
5. **BR-07 scope (OD-07-E).** The balance gate (`user.BlockPrintOnRemainingBalance && !_currentUser.IsAbsolutePermission && BalanceProbe.Balance(patientId) > 0` → `Error.Conflict("يوجد رصيد متبقٍ على حساب المريض؛ لا يمكن الطباعة.")`) applies to the combined report and to every history report; the blank report carries no balance gate.
6. **History auto-insertion master switch.** `AutoInsertHistory` never fires when `ReportSettings.HistoryAutoDisplayEnabled == false` (FR-M07-005); manual insertion works regardless of the switch.
7. **History lines are copies.** Auto/manual history insertion copies prior result values into the report model; no original `PatientTest` row is ever modified by a report operation.
8. **Print audit.** Every actual print updates `MarkPrinted` per printed line (`PrintCount` increment + `LastPrintedByUserId`/`LastPrintedAtUtc` — Blueprint §9) via the existing `PatientTest` mutators.
9. **Permission gate.** Every print command carries `IAuthorizedRequest` with `RequiredPermissionCode => "PRINT_RESULTS"` (seeded id=4). Read queries are open (no `IAuthorizedRequest`), per the established read policy.
10. **Frozen snapshots only.** No report query reads a live reference range — combined lines read `PatientTestReferenceRangeSnapshot`; profile lines read `ProfileResultItemReferenceRangeSnapshot` (M-05 pattern).
