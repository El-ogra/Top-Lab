### 5.1 M21-S1 — M21 application: queries and `MarkSampleDrawnCommand` + tests

- **Objective.** Build the M21 Application feature folder with the two queries and the two commands that the phlebotomist screen will consume. The Domain `PatientTest.MarkSampleDrawn` mutator already exists; the Application layer is the new surface.
- **Files / classes to add or change.**
  - **Add** `src/TopLab.Application/Features/SampleCollection/Common/SampleCollectionDtos.cs` — DTOs: `PatientWithUndrawnTestsDto` (patient summary + count of un-drawn tests + earliest registration time), `PatientTestDrawDto` (full `PatientTest` projection with the `Test.Name` resolved), `SampleDrawBoardDto` (groups `PatientTestDrawDto` rows under a patient header).
  - **Add** `src/TopLab.Application/Features/SampleCollection/Common/SampleCollectionAccessPolicy.cs` — permission code constant: `public const string AddEditPatient = "ADD_EDIT_PATIENT";` (re-uses the M02 code; mirrors the M02 `AccessPolicy` shape).
  - **Add** `src/TopLab.Application/Features/SampleCollection/Queries/GetPatientsWithUncollectedSamples/GetPatientsWithUncollectedSamplesQuery.cs` and `...Handler.cs` — returns the list of patients that have at least one `PatientTest` where `!IsSampleDrawn && !IsTakenOutsideLab` and the patient is not soft-deleted. Ordered by `RegistrationDateUtc asc` (FR-M21-001: "selecting a patient from the list on the right"). No `IAuthorizedRequest`. The query accepts an optional `DateOnly? Day` filter (defaults to today UTC). Validator: page size ≤ 500.
  - **Add** `src/TopLab.Application/Features/SampleCollection/Queries/GetPatientTestsForDraw/GetPatientTestsForDrawQuery.cs` and `...Handler.cs` — returns all `PatientTest` rows for a patient grouped into two lists: `Drawn` and `NotDrawn` (FR-M21-001: "displays it at the bottom of the window"). Each row resolves the test name via the M12 `Test` set. No `IAuthorizedRequest`. Validator: `PatientId` must be > 0.
  - **Add** `src/TopLab.Application/Features/SampleCollection/Commands/MarkSampleDrawn/MarkSampleDrawnCommand.cs` and `...Handler.cs` and `...Validator.cs` — `MarkSampleDrawnCommand(int PatientTestId, DateTime DrawnAtUtc)`. Handler: loads the `PatientTest` (rejects `NotFound`); asserts the patient-test is not soft-deleted (rejects `Conflict`); asserts the patient is not soft-deleted (rejects `Conflict`); asserts `!IsTakenOutsideLab` (the FR-M21-001 model is for in-lab drawing; outside-drawn is set at order time and is **not** something M21 changes — rejects `Conflict` with the message `"تم تسجيل العينة كمسحوبة خارج المعمل؛ لا يمكن تعديلها من شاشة السحب"`); calls `patientTest.MarkSampleDrawn(_dateTime.UtcNow)`; saves. Returns `Result.Success()`. Permission: `IAuthorizedRequest` with `RequiredPermissionCode => SampleCollectionAccessPolicy.AddEditPatient` (i.e., `"ADD_EDIT_PATIENT"` — settled OD-8; the phlebotomist's role is the same operational write as the registrator's).
  - **Add** `src/TopLab.Application/Features/SampleCollection/Commands/MarkAllSamplesDrawnForPatient/MarkAllSamplesDrawnForPatientCommand.cs` and `...Handler.cs` — convenience command for the phlebotomist to mark **every** not-drawn test for a patient as drawn in one action. Iterates the patient's `NotDrawn` list, calls `MarkSampleDrawn` on each, saves once. Same permission `ADD_EDIT_PATIENT`.
  - **Add** `tests/TopLab.Application.Tests/Common/Fakes/FakeApplicationDbContext.cs` (extend) — no new entity types are needed; `PatientTest` and `Patient` are already in the fake. The slice may add a `Remove<PatientTest>(...)` branch if the existing fake's `Remove` is missing.
  - **Add** `tests/TopLab.Application.Tests/Features/SampleCollection/`:
    - `GetPatientsWithUncollectedSamplesQueryHandlerTests.cs` — patients with at least one un-drawn in-lab test are returned; patients with only outside-drawn tests are **excluded**; patients with only drawn tests are excluded; soft-deleted patients are excluded; the optional `Day` filter works.
    - `GetPatientTestsForDrawQueryHandlerTests.cs` — returns the two groups correctly; resolves the test name; empty patient → empty DTO with the right `PatientId` echo.
    - `MarkSampleDrawnCommandHandlerTests.cs` — happy path (sets `IsSampleDrawn=true` and `SampleDrawnAtUtc=now`); unknown test → `NotFound`; test on a soft-deleted patient → `Conflict`; test that is `IsTakenOutsideLab=true` → `Conflict` with the specific message; double-draw is idempotent (re-drawing an already-drawn test is a no-op success — matches the established M17 pattern for re-issuing commands).
    - `MarkAllSamplesDrawnForPatientCommandHandlerTests.cs` — happy path; only `!IsTakenOutsideLab` and `!IsSampleDrawn` rows are touched; saves exactly once.
    - `SampleCollectionAuthorizationTests.cs` — analogue of the M14 tests. Asserts every write command carries `RequiredPermissionCode => "ADD_EDIT_PATIENT"` and the standard denial message is returned when the user lacks it.
- **Dependencies on prior slices.** M02-S1 (for the `IsDeleted` flag and the `(PatientId, IsSampleDrawn)` index — both are the schema dependencies M21 has on M02); M02-S2 (for the `PatientRegistrationAccessPolicy` shape and the `ADD_EDIT_PATIENT` permission code — code-shape dependency only); M12 (for the test name resolution).
