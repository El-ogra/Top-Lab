A. Patient, reception & order entry
F1 — Register a new patient and raise a lab order — Reception officer (موظف الاستقبال), main window p35. Pages: 35 [D], 3 [D], 36 [S], 4 [S]. Workflow: add patient (name, age/sex, telephone, referring doctor/entity — fields on p6) → system issues a patient code/barcode (e.g. 1116010310011, 1016122510012, 1716010210139 — p26, p29, p38) → select requested tests from catalogue/groups → auto-price → print stickers and/or receipt. Inputs: demographics, referrer, test list, account type. Outputs: patient+order record, barcode labels, receipt, "Receive date" stamp (28.12.2016 09:00 PM, p4). Rules: account type drives pricing (F42); barcode is mandatory and reused for entry/search/delivery (p52); work papers are ranged by first and last patient code (p8). Depends on: F2, F3, F33, F42, F5.

F2 — Vertical barcode coding ("التكويد العمودي") and sticker printing — Pages: 3 [D+S], 52 [D], 5 [D], 6 [D]. Workflow: the system groups the patient's tests by sample type and prints a sticker per container (tubes, containers, swabs). Labels shown carry the test name/short code (106, 1.5 T.Lip, ALP, SGPT, Cholesterol, HDL, LDL, Creatinine, ESR, عينة بول, سائل منوي, براز), patient name, age, request date/time, a status symbol, and a lab code for following the patient's medical history. Rules: sticker size configurable — one example 38 mm × 25 mm (p3). Vertical coding can optionally be printed on result reports, the receipt and the envelope (p3). Sticker content and shape can be modified and any sticker re-printed (p52). Separate labels for the patient file, the lab card, and a website result-delivery label carrying a password (p3). The doctor can edit the distribution of tests across the drawn sample and containers (p3).

F3 — Cashier receipt printing — Cashier/reception. Pages: 4 [D+S], 5 [D+S], 52 [D]. Workflow: print Patient Name, Patient Info (sex–age), Receive date, Doctor Name, "Results PW" (web-delivery password, e.g. 134X 2V3E 41), per-test line + AMOUNT, then Total → Discount → Net Invoice → Paid → Residuum, then lab identity block and "Thank you for visiting RealLab!". Two formats: (a) thermal/cashier roll (p4); (b) A4 lab paper or normal paper with added header, footer and logo (p5). The A4 version prints a [No. of tests] / [Price] table grouped by profile (e.g. LIPIDS PROFILE >> LDL, TG, Chol). Rules: test detail lines, barcode and program counters each showable/hideable at print time (p4, p5); free lines for writing lab data / serials — the count is [unclear] (p4); web result-receipt data can be printed on the receipt or suppressed (p5); test prices showable/hideable (p52).

F4 — Print the lab order / requisition ("أمر") per patient — Reception + samples officer. Pages: 6 [D+S]. Prints Pat. Name, Age/Sex, Telephone, Referred by, Date, Time, Total, Paid, Charge, and a table Test Name | Unit | Result | Collection Notes | Sig., with "Printed By admin" and reception/samples-officer signature lines. Rules: one form per patient to prevent error, ease follow-up, allow archiving (p6); a copy can be printed for the patient whether the report has already been printed or not (p6); the doctor can re-order tests per individual (p3); the print position and visibility of each element is controllable (p6).
